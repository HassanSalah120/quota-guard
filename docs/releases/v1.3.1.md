### What changed

- Compact charcoal/mint popup with a fixed 400px width, keyboard navigation, and separate actual-quality and requested-limit readings.
- Small player chip shown on hover or focus, positioned clear of player controls.
- Facebook quality automation no longer clicks player menus or Close controls. A trusted Home-to-Reel click authorizes the newly mounted viewer once without allowing unrelated feed autoplay.
- Media sizes use server-reported full resource sizes or bytes successfully appended to the current player's MediaSource buffers. Unknown sizes stay unknown; there are no estimates or claimed MB savings. Buffered bytes are not full video size or internet usage.
- Stream filtering handles chunked responses, body readers, clones and UTF-8 boundaries. Disabled settings bypass filtering; activity/settings writes are serialized across tabs.
- TikTok uses actual 540p/720p settings. YouTube playback controls that cannot be enforced are disabled; audio only is labeled as a request.
- Refreshed README, SVG/PNG branding, screenshots and promotional images. Release packaging now uses an explicit runtime file allowlist and excludes development files and signing keys.

### Install or update

Extract `quota-guard-v1.3.1.zip` into a permanent folder. Open `chrome://extensions` or `edge://extensions`, enable Developer mode, and choose **Load unpacked** → the folder containing `manifest.json`.

For an existing unpacked installation, extract over its existing folder, click **Reload** on the extension card, then refresh all open supported websites. Keeping the same installation preserves local preferences. The media ZIP is artwork, not the extension.
